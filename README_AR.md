# القرآن الكريم — إسلام صبحي (نسخة أولية)

تطبيق أندرويد تجريبي يعرض السور من دليل MP3Quran.net ويشغّل ملفات التلاوة عبر الإنترنت باستخدام Android Media3 وMediaSessionService لدعم التشغيل في الخلفية.

## إنشاء ملف APK باستخدام الهاتف فقط

1. أنشئ حسابًا مجانيًا في GitHub من متصفح الهاتف.
2. أنشئ مستودعًا جديدًا (Repository) باسم `QuranIslamSobhi`.
3. ارفع محتويات هذا المجلد كاملة إلى المستودع، مع إظهار الملفات المخفية مثل مجلد `.github`.
4. افتح تبويب **Actions**، ثم اختر **Build Android APK** واضغط **Run workflow**.
5. عند انتهاء البناء بنجاح، افتح تشغيل الـ workflow ونزّل ملف artifact المسمى `Quran-Islam-Sobhi-debug-apk`.
6. فك ضغط الملف الذي نزلته، ثم ثبّت `app-debug.apk` على هاتفك. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## ملاحظات

- يتطلب الإنترنت؛ لا يدعم الاستماع دون اتصال في هذه النسخة.
- يعتمد على API ومخدمات MP3Quran.net؛ قد تتغير الاستجابة أو الروابط، لذلك يلزم اختبار عملي قبل النشر.
- تأكد من شروط استخدام مصدر الصوت وحقوق التسجيلات قبل نشر التطبيق علنًا أو تحقيق دخل منه.
- هذه نسخة أولية وليست إصدارًا مختبرًا على جميع الأجهزة.
